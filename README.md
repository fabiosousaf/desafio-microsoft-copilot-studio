# Projeto Copilot - Demonstração Prática

Este repositório contém exemplos práticos de criação de assistentes de IA (Copilots) utilizando diferentes abordagens.

## 📚 O que foi aprendido

Neste conteúdo, explorei três formas de criar um Copilot:

### 1. Copilot baseado em modelo
- ✅ Utilização de modelo de IA pré-existente
- ✅ Rápido desenvolvimento com capacidades herdadas
- ✅ Exemplo: Modelo de agentes 'Viagens Seguras'

### 2. Copilot baseado em descrição de IA
- 📝 Criação via especificações textuais
- 🔍 IA interpreta descrições em linguagem natural
- ✨ Exemplo: Modelo de agente de viagens

### 3. Copilot em branco
- 🏗️ Desenvolvimento do zero
- 🎚️ Controle total sobre funcionalidades
- 🛠️ Exemplo: Modelo de agente de viagens
