# Aprendizados sobre o Microsoft Azure

Este documento resume os principais conceitos e ferramentas que aprendi sobre os serviços do Microsoft Azure voltados à inteligência artificial e linguagem natural.

## 🧠 Capacidade de Processamento de Linguagem Natural no Azure

O Azure oferece serviços robustos para o **Processamento de Linguagem Natural (PLN)** por meio do Azure AI Language. Com ele, é possível:

- Analisar sentimentos, opiniões e emoções em textos.
- Extrair entidades, palavras-chave e informações estruturadas.
- Detectar o idioma automaticamente.
- Classificar documentos por categorias com base em aprendizado de máquina.
- Criar modelos personalizados para entender linguagem específica de domínio.

## 🤖 Serviço de Bot do Azure

O **Azure Bot Service** permite criar, hospedar e gerenciar bots inteligentes que interagem com usuários em múltiplos canais (como Microsoft Teams, websites e Facebook Messenger). Com ele, aprendi:

- Como integrar bots ao **Language Understanding (LUIS)**.
- Criação de fluxos conversacionais interativos.
- Conexão com APIs externas e banco de dados.
- Uso de templates e ferramentas como o **Bot Framework Composer**.

## 🗣️ Compreensão da Linguagem Coloquial

Um dos diferenciais do Azure AI é a habilidade de compreender **linguagem coloquial, informal e contextualizada**. Isso é possível por meio de:

- Modelos treinados com grandes volumes de linguagem natural real.
- Reconhecimento de gírias, abreviações e expressões populares.
- Customização de modelos para domínios específicos.

Essa capacidade melhora significativamente a qualidade das interações com usuários reais, especialmente em ambientes de atendimento ao cliente e assistentes virtuais.

## 🎙️ Speech Studio

O **Speech Studio** é uma plataforma baseada na web que oferece ferramentas para explorar e usar os serviços de fala do Azure. Com ele, aprendi a:

- Converter fala em texto (Speech to Text) com alta precisão.
- Gerar voz a partir de texto (Text to Speech) com vozes neurais realistas.
- Criar e treinar vozes personalizadas.
- Realizar tradução de fala em tempo real.
- Testar e ajustar configurações de forma intuitiva e visual.
